## Windows 兼容修复

全量测试发现远程脚本依赖 POSIX `fcntl` 和系统时区数据库，且 Windows 路径及换行符会导致研究校验失败：

- `process_lock.py` 使用 Windows 的非阻塞字节锁或 POSIX `flock`，四个股票模拟脚本在完整执行周期内持锁，异常退出后由操作系统释放。
- requirements 为 Windows 增加 `tzdata==2026.5`。
- `.gitattributes` 固定 Python 脚本和配置 JSON 的 LF 换行符，保留冻结文件内容哈希；没有重算或修改冻结配置中的哈希。
