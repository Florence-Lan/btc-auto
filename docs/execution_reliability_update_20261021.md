# 模拟执行可靠性修复（2026 年 10 月 21 日晚，北京时间）

已修复并应用到模拟服务：成功的备用时间请求不再因前一次失败请求耗时被误拒；已有实验启动遇到公共时钟故障时保留账本并进入受限运行，下轮继续重试。五项模拟服务已恢复。均线、四小时确认、仓位、止损、费用假设、回撤预算及交易模式没有调整。

本轮目标是保留成功时间请求 **不超过五秒**、原始接收观测 **不超过十五秒** 的限制；切换期间金融和历史文件 **零字节改动**；每项服务只有一棵有效写入进程树。真实来源故障继续阻止增加风险，保护退出依赖有效的新鲜行情，不能声称网络已经不会再超时。

**修复内容**

`PublicAster.get()` 原先会先尝试 requests，再在失败时使用同一 HTTPS 地址的 curl。上层把整个调用计入五秒限制：即使第一栈等待十七秒失败、第二栈很快返回真实新时间，也被当成慢时钟拒绝。

现在时间端点在成功网络请求内部记录开始和收到时间，验证该次请求的耗时；消费者继续使用原始收到时间，拒绝过期、未来、倒置、非有限或无效的时间元数据。并发共用请求返回独立副本，不允许后来的消费者重盖收到时间。成功请求本身超过五秒仍拒绝，消费时超过十五秒仍拒绝。TLS、代理、HTTP 限流冷却、请求预算、凭证隔离及其它端点保持原规则。

两个股票对照 runner 原先在启动阶段直接获取交易所时间，网络异常可使进程立即退出。现在先验证已有 manifest、全部账本及规则，再局部处理可恢复的公共时钟故障；正常轮询会记录 degraded、暂停新增风险，仍按原规则使用独立新鲜 mark 和盘口管理已有仓位。下轮取得有效时间后恢复。新实验仍须获得验证过的交易所时间才能建立起点；损坏账本、缺失历史及非预期错误继续抛出。

**数据日期的处理**

股指、国债及外汇的部分滞后来自已有的本地保守可用时间模型：日频股指／美债等估算两天，美元／外汇十天，前瞻再取估算可用时间与真实 first-seen 的较晚值。这些是本地声明，不是经核实的官方精确发布时间，本轮没有把它们改成即时数据或放宽观察阈值。

旧油价仍按真实观察日识别，过期时省略。更及时的能源或盘中外盘来源需要单独候选和前瞻证据，本轮没有将未经验证的新闻方向或新来源塞入主策略。财报日历的现有到期时间和门禁保持，继续按例行维护计划处理。
