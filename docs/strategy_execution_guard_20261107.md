# 2026-11-07 模拟盘执行保护修订

本轮将全量交易复盘中的风险教训落实到原主盘三个股票账户。只增补执行保护这一组规则，不改入场趋势、多空方向、宏观过滤、技术止损距离或杠杆上限。BTC 没有足够的新规则成交样本，本轮保留其策略。用户本轮已授权按复盘修改策略。

目标：每笔原计划亏损不超过 `min(20 USDT, 入场权益×2%)`；按当前反向盘口深度与不利基差压力估计的计划亏损不超过原 `min(25 USDT, 入场权益×2.5%)`；净目标保持至少100 USDT、杠杆上限保持10倍。跳空、未来流动性和检查间隔仍可能使实际损失超过计划。

## 具体变化

| 复盘教训 | 实现 |
| --- | --- |
| MU 11/4 接近25预算的计划，实际净亏26.7625 | 对原预算再留20%执行余量。原净目标所需数量若超出20/2%计划预算，跳过，不擅自缩量降低净目标，也不收窄技术止损来强行通过。 |
| 看最优价不能代表整个仓位的退出成本 | 入场预检和实际IOC成交后的最终准入均模拟反向全仓退出，沿用每档10%参与率、50bp价格带及2bp不利滑点模型。反向深度不足，拒绝新增仓位。 |
| 标记价与可成交盘口有明显差异 | 以反向深度VWAP对mark的不利偏离做压力检查；先移除VWAP内已计的固定模型滑点，再计压力，避免同一滑点重复入账。压力预算只是估计，不保证止损时仍有同样深度。 |
| 原利润锁只按价格比例，实际还需付费 | 沿用现行MU 8%/3%、SNDK/SK 4%/1%的启动/锁定比例，报价触发价按已付入场费、退出费、已知资金费与模型退出滑点反解。只收紧已有止损，不放宽。 |
| 小时收盘等待与监控缺口 | 当前主盘11/2已经有逐次可成交报价保护，本轮复用并加强成本口径；不把旧盘的小时等待问题重复修成另一个入场/退出模型。新的持仓风险判断基于完整退出深度，日志保留价格、数量、预算、时间戳、检查间隔及不可评估原因。 |
| 提前“突破失败退出”损伤赢家、放宽确认增亏 | 不启用这些亏损对照，不取消四小时等现有确认，不恢复98个已取消账户。 |

新仓在完整深度估计的净亏到达预留后的预算时请求退出，给原25预算留下余量。已武装的成本后利润锁若被可成交净值跌破，也请求退出。旧保护止损、账户风险、时间退出和资金费保护保留优先执行；辅助深度、行情或时钟不可用时，不伪造退出价格，也不屏蔽原止损。

这会降低交易频率：净目标100和计划风险20隐含需要更大的净收益风险比。用户原来的100净目标没有降低；没有把“零成交”称为策略盈利改善。

## 验证与样本边界

新增定向测试覆盖：MU 11/4记录在风险预留下被拒绝；多空对称基差压力；不重复计滑点；反向深度不足；净利润锁的手续费/资金费等式；原技术止损保留；真实模拟引擎成交；最优价未触及止损而完整深度已超预算的退出；小时行情缺失时利润锁可武装；时钟失败时原保护止损仍成交；完整规则迁移链与资金/已消费信号保全。

对已经看过的23笔股票入场进行固定规则诊断，用统一1000权益、当前技术模型及当时保存的盘口评估：原净100预算模型可接纳13笔，新增执行保护可接纳9笔。它不是收益回放，不包含被拒绝后再次入场的完整路径，也不是独立前瞻验证。11/4 MU的精确权益测试使用997.5861，预留后计划上限19.9517，该笔原计划无法通过。

首次全量测试中22项因Windows默认GBK读取UTF-8测试文件失败，随后按生产服务采用的UTF-8运行方式重跑；不为此修改交易逻辑或放松解码。结果为 **3260 passed, 2 skipped, 43 subtests passed**。测试结果及激活证据保存在 `data/research/strategy_execution_guard_20261107/`。

## 生效与回滚

准备、暂停、持锁保全、应用、恢复、运行核验分步执行。只重启原模拟监督器及两个原服务。迁移保持原账户本金、创建时间、余额、成交、资金费、库存、已消费信号和此前规则时钟；取消旧待成交信号，只有新边界后的信号可使用新执行保护。启用时核对三个股票空仓，不自动平仓或重置。

新配置为 `config/stock_execution_guard_20261107.json`；主盘仍为 `SIMULATION / live_orders_allowed=false`。精确生效时间以 `applied.json` 为准，恢复与各账户实际加载结果以 `verified_live.json` 为准。历史回测与诊断不计入启用后的前瞻成绩。

实际于北京时间 **18:17:35.182** 生效，**18:17:55** 恢复原包装器，**18:18:13** 完成运行核验。三个股票状态均确认加载 `main_execution_reserve_v1`；原102账户与98个取消账户的金融历史前缀核验通过，主盘初始本金合计仍4000。启用后首轮股票均空仓，余额与24笔旧交易完整保留。服务列表只有 `main`、`btc_signals`，原观察器和终端进程身份保持。

回滚需先停止原写入进程并取得原锁；核对新规则仓位与待退出状态后，按新修订记录恢复旧配置和已审查源码，保留新发生的交易与金融日志。`stopped_before/`是本次迁移证据，不能直接覆盖恢复运行后已追加金融活动的状态。没有新金融活动时，可按备份恢复配置/状态并记录回滚时间；新仓仍存在时必须保留其既定保护，不能以回滚放宽止损。
