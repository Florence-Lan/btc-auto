## 连续运行机制

监督器 `scripts/run_paper_services.py` 接管原主服务和 BTC 信号服务，并启动 SNDK 影子服务。每十秒核对进程身份和心跳；进程退出、持续心跳停滞或 BTC 评估子进程超时后，清理已验证的进程组并按 5 至 300 秒退避恢复。正常行情提供方故障不会单独引起重复重启，新增风险仍受原引擎数据与风险门槛限制。

Windows venv 的启动器与实际 Python 子进程按同一服务组识别，避免误当重复实例。源码路径、命令参数和进程创建时间共同校验身份，原生进程句柄防止误杀重复使用的 PID，Job Object 管理后续子进程。真实临时 Windows 进程树的接管、未来子进程继承和清理测试已通过。实际再次启动监督器被独占锁拒绝，退出码 73，原监督器继续运行。
