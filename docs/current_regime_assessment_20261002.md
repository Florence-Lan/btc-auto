## 不同局势下能否赚钱

以下是机制判断，不是各局势已经测得的未来盈利概率。

| 局势 | 当前机制 | 盈利判断与主要限制 |
|---|---|---|
| 连续上涨，宏观同步改善 | 小时趋势做多，五分钟模块寻找顺势回调，因子可放行 | 有盈利机会；要求趋势持续到足以覆盖成本。新账户不会补买启动前已有的旧信号，可能错过部分行情 |
| 连续下跌，美元/利率走强 | 价格策略可以做空，方向匹配的因子可放行 | 有盈利机会；历史不同区间的空头表现差异很大，不能认为跌市必赚 |
| 横盘、假突破、来回反转 | 五分钟模块常因强趋势门槛不入场；小时仓位可能反复反向 | 较弱。减少交易可能避免部分损失，但没有启用专门赚区间波动的模块 |
| 先大涨后急跌，或急跌后 V 形反弹 | 小时 EMA 确认退出较慢，五分钟模块有独立保护退出 | 容易回吐趋势利润或持有错误方向。两套模块的退出保护不同 |
| 通胀/加息压力与 BTC 上涨并存 | 六因素相互抵消、缩小仓位，严重方向冲突可禁止入场 | 可能少亏，也可能少赚或错过趋势；当前环境接近这种情况，未证实过滤能提高净收益 |
| 非农/CPI/FOMC 公布 | 公布前后禁止新入场，结束后等待正常价格信号 | 核心目标是回避开仓风险，不能自动赚到事件波动，已有仓位仍有事件风险 |
| 战争、流动性紧张、暴跌 | 风险代理与新闻降低暴露，极端压力阻止两边新增风险 | 防守优先；不能预知突发事件，首次收到消息前和现有持仓都有风险 |
| 数据缺失、过期或接口故障 | 任一必要因素组不可用即阻止新入场 | 空仓时没有交易利润；完整覆盖要求也会减少机会，不代表策略具有市场优势 |

## 后续判定标准与本次核验

当前最需要证明的是：六因素入场过滤是否在相近风险暴露下提高净收益，以及是否能在震荡/反转中少亏而保留大趋势利润。提高杠杆或增加资讯来源都不能替代这两项证据。

可使用现有执行验证计划的前瞻最低要求：90 天、30 个已结束持仓/交易样本、盈利因子至少 1.3、最大回撤不超过 15%，并核查双倍成本、利润集中度和真实首见数据。这里的样本计数需统一口径，不能混用交易成交、策略交易与账户持仓段；达到最低样本量本身也不等于通过经济验收。新规则研究应先固定参数、保留后续未见数据，与原版及固定仓位对照比较。

本次核验：冻结价格引擎/配置哈希通过；实际读取当前选择、账户、最新策略目标和六因素输出；已检查日历开仓窗口，以及高压力和缺失数据的双向拦截。没有修改策略参数、账户或调度。未重跑全项目测试，也未把工程可运行解释为盈利合格。
