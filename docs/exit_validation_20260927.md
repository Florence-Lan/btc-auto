# 组合记账修复与退出机制验证（2026-09-27）

已修复候选策略使用的分层回撤组合记账，并完成预先限定的退出规则、成本压力和因子对照。结果不支持替换当前退出规则：两种新规则在近期样本中改善，但在隔离验证段均亏损。没有为了获得正收益继续搜索参数，也没有改动实盘设置或启动交易服务。

## 已修复的记账

`execution_ledger.py` 从原冻结子策略的收盘记录还原每笔交易的剩余数量、累计现金损益和费用。元数据按初始单位数量归一化，在宏观、多因子、事件过滤之前生成，缩量时不会重复缩放或重复扣费。`portfolio_risk.py` 用这份记录重建组合：

- 部分止盈后减少实际剩余数量，并释放相应杠杆容量。
- 入场费、部分已实现损益和资金费按可获得的子策略记录入账；浮动损益只计算剩余数量。
- 可用杠杆容量使用当时盯市权益，包含已知费用及估计平仓手续费。
- 小时记录在小时结束后才可用；小时期末估值不再在最后一小时开盘提前兑现。
- 同时发生的旧仓退出先于反向开仓结算，新仓费用先于下一笔同刻入场的容量检查。
- 分层风控继续保留触发硬回撤后的停止新开仓状态。

当前候选模拟路径（`--tiered-drawdown`）已使用修复后的组合器。冻结的 `simulate_range_swing.py`、已有冻结配置及哈希均未改写；该文件内旧的非分层历史组合器仍保持原样，不能将它产生的旧报告视为新账本结果。缺少子策略曲线/配置的旧交易记录只能使用端点近似，并在 `legacy_endpoint_trades` 中明确计数；本次所有正式比较该计数均为零。

真实 90 天数据逐点核对，在不触发组合容量限制时：5 分钟模块 26,027 个收盘观察、小时模块 2,168 个收盘观察都与子策略权益一致，最大误差分别约 `1.4e-14`、`1.1e-13`。两模块最终权益也分别完全对上。期末合成平仓包含真实模拟的退出费用和滑点，因此其最后一点可能不同于平仓前的估计净值。

## 固定研究规则和时间隔离

运行比较前，已保存 [研究计划](../config/exit_research_plan_20260927.json)。只比较三种规则，入场参数和仓位上限保持一致：

1. **baseline**：原均线差值反向达到阈值时退出。
2. **neutral**：小时收盘时均线方向转弱至零/反向，下一小时开盘退出。
3. **volatility**：用入场前已完成小时 K 线的 ATR(14)，亏损达到 2 ATR 或从最佳收盘价回吐 3 ATR 时，下一小时开盘退出。入场 ATR 固定，不使用未来最大浮盈。

保留原有“重新跨过阈值才入场”的要求；没有新增止损后立即重入。所有新增退出使用已完成的小时 K 线，之后开盘成交，含手续费、滑点/冲击和资金费。

新增获取 2025-11-01 至 2026-04-15 的行情，包含 47,520 根 5 分钟 K 线、3,960 根小时 K 线及 495 次资金费记录，K 线连续无缺口。2025 年 11—12 月用于指标预热。

- 开发段：2026-01-01 至 2026-03-01，不含右端点。按小时模块的“净收益百分点 − 最大回撤百分点”选择，平分优先基线。
- 隔离验证段：2026-03-01 至 2026-04-15，不含右端点；不用于选择阈值或改变规则。
- 已知压力段：2026-06-29 至 2026-09-27 09:00 UTC。
- 已知近期段：2026-08-30 至 2026-09-27 09:00 UTC。

每段从空仓开始，先前行情仅用于指标预热；与连续持仓跨越边界的收益口径不同。最近 90 天在上一轮诊断时已经看过，因此**不是未见过的样本外数据**。新增验证段在本次规则选择中隔离，但整个策略本身是在这些历史日期之后设计的；这是回顾性时间隔离验证，不能称为真实前瞻交易验证。

## 退出机制结果

小时模块单独比较：

| 区间 | 原反向退出：净收益 / 回撤 | 趋势转弱退出：净收益 / 回撤 | 波动率退出：净收益 / 回撤 |
|---|---:|---:|---:|
| 开发段（1—2 月） | +9.8152% / 4.0443% | +9.1575% / 4.0443% | +3.6007% / 0.9038% |
| 隔离验证（3 月 1 日—4 月 15 日） | +0.3122% / 3.5208% | −0.4861% / 4.2886% | −1.1367% / 1.4079% |
| 已知 90 天压力段 | +8.2848% / 5.6034% | +9.6126% / 4.6436% | +0.3316% / 3.0487% |
| 已知近期段（约 28 天） | −0.5169% / 3.7935% | +0.0391% / 3.2559% | +1.7719% / 1.8021% |

开发段预设评分选中的是 **原基线**，不是新退出规则。验证段已完成交易数只有原基线 4 笔、趋势转弱 5 笔、波动率退出 6 笔。原基线的交易手续费和滑点/冲击翻倍、保留相同资金费后，验证净收益为 +0.1906%，回撤 3.6158%。由于交易数不足，预设的至少 20 笔已完成交易条件也未通过。20 笔是本次最低研究门槛，不是满足后即可证明稳定盈利。

加入原 5 分钟模块后的组合结果：

| 区间 | 原反向退出：净收益 / 回撤 | 趋势转弱退出：净收益 / 回撤 | 波动率退出：净收益 / 回撤 |
|---|---:|---:|---:|
| 隔离验证 | +0.3122% / 3.5208% | −0.4861% / 4.2886% | −1.1367% / 1.4079% |
| 已知 90 天压力段 | +8.6864% / 5.5440% | +10.0070% / 4.5944% | +1.1502% / 2.9569% |
| 已知近期段 | −1.2484% / 3.7935% | −0.6965% / 3.2559% | +1.0252% / 1.8021% |

波动率退出确实保住了近期的一部分盈利，但也明显缩短了持仓，削弱大趋势收益；90 天小时模块平均总杠杆从约 0.36 倍显著降低，组合平均总杠杆从 0.3680 倍降至 0.0880 倍。仅看到回撤变小，不能据此认定预测能力改善。没有因近期 +1.0252% 的组合收益就切换规则。

旧宏观过滤先与**开发段平均总杠杆匹配**的固定缩量比较：开发段得到固定系数 `0.6253128051757812`，其平均总杠杆 0.185888，与宏观过滤的 0.185886 接近。这个固定系数随后原样用于验证段，没有按验证收益重选。

| 开发：原宏观过滤 | +6.5619% | 2.7960% | 0.185886 |
| 开发：暴露匹配固定缩量 | +6.4120% | 2.7395% | 0.185888 |
