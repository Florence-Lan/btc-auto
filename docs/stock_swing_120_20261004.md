# 三只存储股票链上波段：10x、净保证金盈利 120% 候选

已写成独立的信号模块、固定配置和组合回测程序。第一版采用四小时趋势突破，目标是每笔初始逐仓保证金净盈利 120%。研究回放确实产生了达标交易，但近期没有达标样本，闪迪和海力士的已平仓贡献为负，因此本版保留为研究候选。

## 交易对象和数据

按用户的“Binance 链上”表述，本版使用 **Binance Wallet 接入的 Aster 永续**：`MUUSDT`、`SNDKUSDT`、`SKHYNIXUSDT`。币安钱包的永续订单实际在 Aster 执行，[币安官方说明](https://www.binance.com/en/support/faq/detail/7a0b1e282453479da1d7216b9cf83402)。这与币安交易所 U 本位合约、股票代币现货的执行接口和历史不同。

使用 Aster 公共 V3 API 的真实合约成交、标记、指数一小时 K 线及资金费率历史；[官方市场接口](https://asterdex.github.io/aster-api-website/futures-v3/market-data/)。MU 和闪迪从 2026-01-30 上市后开始；海力士从 2026-05-29 上市后开始。上市小时不完整的 K 线被排除，四小时指标只使用四根完整小时线。最后完整小时截止北京时间 **2026-10-04 20:00**，结束时间不含。

此前现货日线统计的 28／37／25 等达标区间是事后机会数量；本策略不读取事后最低点，也不把那些数量当成可成交盈利次数。海力士合约的价格已包含指数和汇率处理，收益直接按 Aster 合约价格计算。

## 固定规则

| 项目 | 规则 |
|---|---|
| 信号周期 | 完整四小时 K 线；200 根预热，约 33 个自然日 |
| 做多趋势 | EMA20 > EMA50 > EMA200，EMA50 高于六根前 |
| 做空趋势 | EMA20 < EMA50 < EMA200，EMA50 低于六根前 |
| 做多入场信号 | 收盘突破此前 20 根最高价；窗口排除信号本身 |
| 做空入场信号 | 收盘跌破此前 20 根最低价；窗口排除信号本身 |
| 避免追价 | 突破幅度不超过 1 ATR14；ATR14/价格不超过 3% |
| 成交时点 | 下一根四小时开盘；不利跳空超过 0.5 ATR 放弃 |
| 开仓过滤 | 已知最近结算费率不利于持仓方向时，不超过 0.03%；资金数据超过九小时未更新则不新增；标记/指数及成交/标记价偏离均不超过 0.5% |
| 初始止损 | 距入场 `max(2 ATR14, 入场价×2%)`；距离超过 5% 放弃；按价步向外取整后复查 |
| 杠杆 | 逐仓 10x；初始保证金为入场名义金额的 1/10 |
| 单笔风险 | 计划止损损失含成交费用和假设止损滑点，不超过当时账户权益的 0.5% |
| 组合风险 | 最多同时两只；三只合计计划止损风险不超过权益 1%，总名义金额不超过权益 1 倍 |
| 止盈 | 扣开平手续费和累计资金费后，净收益达到初始保证金的 120%，全部平仓 |
| 获利保护 | 已收盘价格顺方向运行到 8% 后，至少锁定标的 3%，按两倍 ATR 收紧止损；只在下一小时起生效 |
| 持有期限 | 最长 15 个自然日，下一小时开盘退出 |
| 资金费预算 | 累计净支付超过初始保证金 10%，安排下一小时退出 |
| 重入 | 平仓后等三个四小时周期，再等新的突破信号；每只同一时刻只一笔，不补亏、不加倍 |
| 账户风险 | 回撤达到 8% 暂停新增，已有退出继续；15% 安排清仓并锁定停机。小时采样与跳空可能超过阈值 |

EMA 以首次完整窗口简单均值初始化；ATR 使用 Wilder 平滑。所有参数在回放前确定，没有参数网格搜索，也没有根据回测成绩改信号。

## “120%”具体赚多少

这里的 120% 是**该笔初始保证金收益率**，不是整个账户收益率。

例：账户 10,000 USDT，入场价 100、初始止损 97、单边费用假设 0.1%、止损滑点假设 0.02%。按 0.5% 账户风险预算和 0.01 数量步长，最多约 15.54 单位，名义金额 1,554 USDT，10x 初始保证金 155.40 USDT，计划止损损失约 49.98 USDT。净保证金盈利 120% 时赚约 **186.48 USDT，即账户约 1.86%**。

涨幅 12% 只对应毛保证金盈利 120%。费用和资金费会让需要的实际涨幅更大。设入场实际成交价为 `E`、数量 `q`、单边手续费率 `f`、累计资金费净支付 `F`（收取资金费时为负），净目标实际平仓价为：

```text
做多：T = (1.12 × E + f × E + F/q) / (1 − f)
做空：T = (0.88 × E − f × E − F/q) / (1 + f)
```

每次结算更新目标，再按平仓滑点和价格步长换算触发价。上述例子若资金费为零，做多目标实际成交价约 112.2122，而非 112。数量不随持仓浮盈追加，初始保证金分母不变。

## 成本和执行模型

统一采用单边 **0.1%** taker 费用、每次成交 **0.02%** 不利滑点，双倍成本将两者翻倍。这是保守费用假设：Aster 当前文档列出了不同费组，海力士与一般 RWA 费率分类不一致，且账户等级、历史费率并未完整还原。[官方费用说明](https://docs.asterdex.com/trading/perpetuals/fees-and-specs/fees)

公开当前小名义金额档位的维持保证金率为 1.5%，允许 10x；额外以 5% 维持保证金率压力回放。[公开杠杆档位](https://www.asterdex.com/en/futures/trading-rules/leverage-and-margin?symbol=MUUSDT) 当前档位不能证明过去各时点规则完全相同；接口 `exchangeInfo` 中注明忽略的保证金占位字段不用于计算。

回放分别使用成交价判断止盈止损、标记价判断假设强平。当同一小时内顺序无法辨别，按强平压力、止损、止盈的顺序处理。强平压力模型以损失该笔初始逐仓保证金结算，不能当作平台真实成交重建。

Aster 资金费历史提供费率和时点，但缺少精确结算标记价，本回放以结算小时的标记开盘价近似资金费金额。晚于小时开盘的结算，在顺序不明时提前计入不利支付；有利收款延至小时末，若同小时已经退出则不虚增这笔收款。[资金费规则](https://docs.asterdex.com/trading/perpetuals/fees-and-specs/funding-rate) 股息特殊结算也应保留，不能仅按时间去重或假设资金周期从未变化。[股息规则](https://docs.asterdex.com/trading/perpetuals/dividend-introduction-for-equity-perpetual-futures)

期末未平仓持仓按标记价估值，单独显示估计平仓损益，不计入已平仓或 120% 达标笔数。当前数量、价格步长用于全历史，未重建历史规则变化。
