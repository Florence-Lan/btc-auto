# 用户的60%收益目标与70%胜率要求

用户明确指定：单笔收益以该笔交易的初始保证金为分母，扣除开平仓手续费、滑点和资金费后，盈利目标至少60%；策略净盈利胜率至少70%。

净收益率 = 已平仓净盈亏 / 本单初始保证金。胜率 = 净盈亏大于零的已平仓交易数 / 全部已平仓交易数。胜率和达到60%收益的交易比例是两个不同指标；后续候选必须分别报告，不能用小额盈利冒充达到60%目标。

这两项要求作为策略研究和准入标准，不能保证每次实际盈利或未来胜率。止损、移动止损、时间退出、资金费预算退出和账户风险退出仍有效，可能产生低于60%的盈利或亏损。不能为了保证账面胜率而禁止止损、忽略未平仓亏损或补仓摊平。
