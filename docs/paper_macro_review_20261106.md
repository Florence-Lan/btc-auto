## 运行问题、验证与恢复

Windows System 日志在北京时间 23:20 左右记录 1074，随后 6006/6005，支持这次全部后台服务消失与系统重启有关。没有证据将该次退出归因于下述编码异常。

另在长期监督器日志中确认多次 `_readerthread` 的 `UnicodeDecodeError`，UTF-8 解码遇到本地编码字节。`run_paper_services.py` 的 PowerShell 进程清单未设置输出编码，而 Python 启动环境启用了 UTF-8，两端协议不一致。修复仅在清单子进程设置 `[Console]::OutputEncoding`，并在 Python 明确以 UTF-8 解码；不忽略或替换坏字节，不削弱进程身份、锁、重试和退出码检查。

真实 PowerShell 回归注入含中文路径的 CIM 结果，在原 936/437 控制台编码下验证进程命令、参数无损往返；中文 stderr 加非零退出仍必须报错。连同监督器、启动循环、主趋势、预算、纳指与跨市场回归 **251 passed**。
