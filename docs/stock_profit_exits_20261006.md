# 股票模拟分批止盈与原规则对照

用户认可“1R先平一半、余仓扣费保本、1.5ATR跟踪退出”。北京时间 **2026-10-06 13:06:47**，当前四账户联合模拟中的MU、SNDK、SKHYNIX启用这一固定退出方案，执行器PID **53983**。BTC继续自身的多因子执行模型。

## 新退出规则

- 1R固定为实际入场价到初始止损价的距离，不随保护位收紧而重新计算。
- 用当前可见买价（多仓）或卖价（空仓）及额外逆向滑点估算退出价，达到1R时退出初始数量的50%，按合约数量步长向下取整。
- 首段限量部分成交后，立即保护余仓，并保留首段剩余待成交数量，每30秒继续按新鲜盘口重试。状态随仓位保存，重启不重复退出一半。
- 余仓保本位包含分摊后的实际入场费用、已结算资金费、假设退出手续费及逆向滑点。保本价再按价格步长向有利方向取整；盘口深度、跳价及后续资金费仍可能导致实际净亏，不能将保护价等同于成交保证。
- 多仓从生效后观察到的最高可执行买价向下留1.5ATR，空仓从最低可执行卖价向上留1.5ATR。ATR取各自信号周期已收盘数据：MU/SKHYNIX为15m，SNDK为5m；每轮使用当前已知ATR及最佳报价，保护位只收紧。ATR不可用时仍可分批退出并设置扣费保本位，现有保护退出继续执行。
- 若初始数量不足以分成两份满足最小数量和名义金额的仓位，则在1R跳过拆分，直接为整个余仓启动保本与跟踪保护。部分平仓成交记录带有position_closed和remaining_qty，不能把每笔退出成交都当成一笔完整交易。
- 账户硬停止、强平保护、当前保护止损、持仓期限与资金费预算优先于分批止盈；保护退出未完成的数量继续保留待退出。
- 本试验取代股票原有净保证金120%固定止盈及标的8%盈利才启用移动保护的条件。以前60%保证金目标、历史研究指标仍为历史资料，不能作为本试验每次退出必须达到的门槛。

## 已有仓位与激活口径

余额、已实现损益、费用、资金费、成交计数、持仓、库存历史、结算去重信息、待入场信号和原信号时点逐项核对，切换时完全一致。新规则只修改退出政策及候选标识，不重置信号激活时点，不补做旧信号。

激活时MU与SNDK各有0.07空仓，SKHYNIX为空仓。新规则从激活后首次新鲜盘口开始记录最佳价格。SNDK此前曾到过1R属于新规则生效前的路径，不补记过去的止盈，也不使用过去低点收紧新保护位。第一轮SNDK/MU尚未再次达到1R，所以没有强制减仓；这是前瞻规则验证的正常等待状态。

## 原规则对照

激活前在同一执行锁下，从三个现有股票账户各复制一份完整现金、持仓及结算状态，形成独立的原退出规则对照账本。两组每轮使用同一批公开市场响应：当前报价、标记价、资金费、已收盘信号/成交量、合约过滤规则；不因两组数量变化伪造对方交易。

比较起点为共同的激活库存。终端分别显示新规则与原规则自起点以来的净值变化、现金变化及净值差额。净值包含未实现浮盈；现金变化包含已实现损益、手续费和资金费，两组不是相加的账户收益。第一轮未触发退出时，两组标记净值及余额完全相同；后续多轮对比也确认股票两组报价、资金费响应及余额一致。后续不同退出会导致入场等待和冷却路径不同，这属于完整前瞻策略路径差异，不能把全部差额都解释为同一笔交易的单独止盈贡献。

新组继续使用原四账户账本。对照目录：`data/parallel_simulation/btc_memory_stocks_1000_each_10x_20261005/profit_exit_comparison_20261006/`。其中manifest保存共同起点和基线；mu/sndk/skhynix各自保存state、observations、fills、closed_trades、funding等事件日志。对照状态在原status.json的profit_exit_comparison中持续更新。

## 资金费与账本

部分退出按数量比例分摊已付入场费、已结算资金费和初始保证金，余额恒等式仍为初始资金+已实现毛损益−手续费+资金费损益。对迟到的资金费，以真实结算时点的库存计算总扣款，只将仍持有数量对应部分分配给余仓；已退出部分记在funding日志的closed_funding_debit中，不能全部转嫁给余仓。复核已平仓收益时需要结合资金费日志，不应只累加退出时的net_pnl字段。
