## 修复的代码缺陷

- Windows Aster 行情回退硬编码 `/usr/bin/curl`，实际日志出现大量 `WinError 2`。改用可找到的 `curl.exe/curl`，维持 TLS 验证与 HTTPS 限制。
- Requests 的连接/读取空闲超时并非请求总时限。公共读取增加墙钟截止；挂起端点不会反复增加守护线程，实例和进程均限制未完成数量，过期结果不写交易账本。该包装仅用于公共读取，未用于带签名写订单。晚到限流响应仍更新冷却。
- IOC 数量取整后仍使用取整前数量的盘口均价。改用实际成交数量对应的深度前缀重新计算均价，保留逐档参与率和不利滑点。
- 模拟配置和状态文件显式 UTF-8 读取，修复 Windows 默认编码读取中文失败；历史重放内存文件适配相同接口。
- 账户独立心跳定期发布，停滞超过 `max(90 秒, 3 × 轮询周期)` 标为降级；不会把旧报价时间改成新报价时间。
- 修复状态文件写入、错误处理内再次读取账本/写日志以及按顺序等待永久循环 Future 导致的失败隐藏。诊断写入失败不再单独杀死账户线程；终止的账户线程会被主线程发现。
