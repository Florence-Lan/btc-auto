# SNDK净期望策略继续修改与新数据验证

本轮实际改写并检验了三种入场假设，没有得到足以确认未来盈利的新版本。原SNDK趋势、成交量与NQ过滤方案有正的历史平均收益，因此冻结它做独立模拟，用未来收到的数据检验。原四账户的暂停准入及已有仓位保护继续执行。

## 本轮修改结果

三种假设分别是：原趋势突破改用更紧的止损；EMA8/24/60趋势中的回撤后确认；压缩区间后的突破。后两者用已收盘1小时线，最近6小时至少4小时有成交，NQ方向一致。三者止损1.25ATR、最低0.75%、最高3%，目标仍是扣成本后初始保证金60%。风险0.25%，模拟初始资金1000 USDT。参数在读取本轮回放结果前写入声明，但历史已经多次研究，不能称为未见样本。

实际完成126个场景：3股票×3假设×（4个窗口×2成本＋4次月初训练＋2成本的连续月度准入）。核对1533条重叠账本记录；这些记录并非1533笔独立交易。所有已平仓入场均复核了当时可用的NQ数据和净收益账目。原30/10/10/50笔窗口样本要求及其他收益、风险门槛保持原样；9组股票/假设均不通过。

## 冻结的新数据模拟

使用原已研究方案：SNDK已收盘1小时EMA20/50/200趋势突破，最新已收盘4小时趋势同向；成交量达到此前20个有成交小时中位数的1.25倍，最近6小时至少4小时有成交；NQ小时EMA20/50及6个观测的斜率、收益同向。NQ只做入场过滤，不单独创造股票信号。

历史双倍成本为15笔、胜率53.3%、净收益9.7911 USDT、均值+0.6527 USDT；正常成本均值+0.7082 USDT。双倍成本平均赢家3.2763 USDT，平均亏损2.3457 USDT：`0.5333×3.2763−0.4667×2.3457≈+0.6527`。去掉最大赢家后均值+0.2306 USDT，但后段只有1笔，占全段利润约67%。这些是有偏的历史样本估计，不能证明未来期望为正。

配置：`config/stock_sndk_net60_shadow_20261005.json`。

连续模拟ID：`sndk_trend_volume_nq_net60_shadow_20261005_v2`。前一ID仅作一次空仓预检，保留其记录；它不是第二轮调参结果。新版开始前冻结源文件、配置与指标种子数据哈希，重启时核对，拒绝悄悄改变策略。

- 两个独立1000 USDT虚拟账户：正常成本与手续费/滑点加倍，资金费按收到的结算数据处理。
- 风险0.25%，10倍为杠杆上限，名义仓位不超过权益1倍；入场不超过此前已收盘5分钟量的10%、可见各档盘口量的10%，买卖价差不超过0.10%。
- 净止盈目标为该单初始保证金60%；止损2ATR、最低1%、最高5%，持仓最多7天，退出后冷却3小时。止损、资金费及时间退出可能亏损，也可能小额盈利。
- 3%回撤限制新增，6%触发保护退出。这些前瞻限制与历史回放不同，其改善收益的效果尚未验证。
- 股票信号只能在启动后新收盘；历史数据仅为EMA预热。收盘行情快照及实际收到的NQ响应保存时间和哈希。
- NQ为公共小时报价，按小时起点加1小时20分钟保守估算可用时间，还必须实际已收到响应。每次入场重试再次检查；NQ可用时间年龄超过90分钟、获取记录超过20分钟、获取失败或缺失都会阻止入场。仍可能存在延迟与数据修订。
- 30天到期后停止新增、继续持仓保护。每种成本至少30笔平仓、净期望为正、去掉最佳盈利单后仍为正、回撤不超过6%、无强平，才进入人工复核；没有自动晋升。30天未有足够样本即记录为未完成验证。

仅使用公开行情GET接口和本地模拟账本。研究账户不改变原四账户或独立BTC账户，也不提交交易所订单。
