## 已启用的执行改进

- 股票新增入场要求 `2 × (ask − bid) / (ask + bid) ≤ 0.001`，即买卖价差不超过中间价的 **0.10% / 10bp**。这项限制与盘口和标记价偏离检查独立，避免两个报价都在允许偏离范围内时，仍因价差过宽入场。
- 价差超限不消费有效信号，在信号过期前继续每30秒检查。保护止损、减仓和平仓不受新增门槛阻挡。
- 模拟页用中文显示价差阻挡原因，并在执行检查发生时显示实际价差及上限。
- 股票单笔新增计划风险仍为权益的0.25%，名义仓位上限1倍、杠杆上限10倍。SNDK继续原已筛查双向突破模拟；MU、SKHYNIX及联合BTC账户继续暂停新增。原独立BTC模拟账户按既有规则运行。

10bp为本轮固定执行成本保护值，没有搜索这个阈值。历史盘口缺失，无法把该限制完整加入OHLC回测，也没有证据量化其盈利效果。保护更严格可能减少成交。

## 在计算前声明的比较

每个股票使用自己的当前双向入场规则，对照保持原2%最小止损和保证金净120%目标；固定五个挑战方案：

1. 仅活跃度过滤：最近12根已收盘信号线至少一半有成交量。
2. 短线退出：0.5%最小止损、保证金净30%目标、最多3天持仓；标的盈利2%后启用追踪，锁定0.5%，继续2ATR追踪。
3. 短线退出加活跃度过滤。
4. 中等退出：1%最小止损、保证金净60%目标、最多7天持仓；标的盈利4%后启用追踪，锁定1%，继续2ATR追踪。
5. 中等退出加活跃度过滤。

ATR止损倍数仍为2，最小止损是下限，并非所有交易固定按下限止损。活跃度过滤只读取被评价信号及此前的完整窗口，未来成交量不能救回旧信号。两个方向都保留，不通过删除亏损方向改善报表。

成本按当前公开费率假设：MU/SNDK单边0.0125%、SKHYNIX单边0.10%，另计单边2bp滑点与历史资金费，并重跑双倍费用/滑点。Aster官方费率列RWA吃单费1.25bp，SKHYNIX为Group B；当前费率应用于旧价格路径只是情景，不能还原历史真实费用。[官方费率](https://docs.asterdex.com/trading/perpetuals/fees-and-specs/fees)

原数据结束于北京时间2026-10-04 20:00，不含该时点；历史此前已经研究过。本轮仍只用2026-09-01 UTC之前的开发段决定是否选择挑战方案，没有独立未见验证声明。

替换要求在正常、双倍成本**分别**满足原净收益、至少20笔、利润因子≥1.15、回撤≤6%、无模型强平门槛，且多空各至少5笔并各自净盈利，去掉最大盈利单仍净盈利，净收益超过对照，回撤不超过对照的110%。按两成本中较低的已平仓净收益排名，冻结后再审查后续区间；失败不改选后续赢家。

若有冻结赢家，后续和最近30天还需满足原样本/利润因子门槛、多空贡献与去掉最大盈利单检查，再进行10bp滑点及5%维持保证金压力检查。零成交量K线上的历史假定成交另列不可验证限制。**本轮开发期无人通过，所以没有运行或挑选后续区间赢家，也未进行这些部署压力情景。**
