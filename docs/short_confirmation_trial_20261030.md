## 研究问题与固定假设

当前主股票信号先要求已收1h Donchian20原始突破及其质量条件，再要求已收4h严格均线方向。价格先下跌而慢均线排序尚未转空时，确认可能滞后。本试验只检验：保留原1h空信号，允许一条固定的价格领先4h确认分支，是否改善实际响应与扣费结果。

候选在short方向满足以下任一分支即可通过4h确认：

1. **原严格4h确认通过**；或
2. **价格领先分支全部成立**：最新完整4h收盘严格低于同栏EMA8和EMA24；EMA8严格低于前一完整4h栏的EMA8；仍满足原`abs(EMA8−EMA60) / 4h_close >= 0.004`。

全部使用同一已闭合4h前缀及原计算方法，不使用正在形成的4h栏，不把1h收盘、即时mark或之后修订的价格冒充该4h收盘。刚好等于EMA或EMA8不下降，不满足新增严格不等式；原严格分支仍可单独通过。

保留0.4%快慢均线离散度，并不表示均线已经空头排序：价格领先分支可能在EMA8／24／60仍多头排列时接纳short，这是待检验的假设，也意味着更容易遇到回抽、假跌破或失去后续赢家。不能将其称为无风险的“提前确认”。

**long方向完全保留原严格4h确认。**没有新增long机制、回踩信号、自动反手、科技弱势自动开空、取消4h确认或降低原1h原始信号要求。原技术层没有short时，候选也不凭板块下跌创造short；已有持仓按原持仓和退出规则管理。

normal与double独立定仓和成交；double同时加倍原taker费用及不利滑点，采用共同观察到的实际资金费结算。不同成本下数量、价格、持仓路径可能不同，不能把二者差额当作单独的策略收益。止损是触发规则，不保证在设定价或一次性完整成交。

## 前瞻记录与评价

至少记录以下三层，避免把“背景转弱”错当一次真实被阻或获利的交易：

- **机会层**：原1h raw方向／边界、原严格与新增4h分支各自结果、拒因、对应EMA与close、前一4h EMA8、原spread、真实first_seen及相对边界lag。同一信号的多次重试不是多个独立机会。
- **执行层**：当前quote、mark、完整执行检查、失效／过期／事件原因、实际fill及费用。两臂共同的输入缺失和拒因单列；没有通过全部原门禁的候选，不记成新增分支成功。
- **金融层**：钱包、权益、资金费、全部费用、完整平仓、持仓数量、原止损与追踪变化、预计完整退出净值及深度是否足够，保留可重放journal与财务完整性状态。

响应目标是量化“同一可见raw short首次出现后，严格与候选确认各何时可用，以及实际何时成交”，而不是比较事后最低价。可按共同边界对齐**信号准入**做诊断；金融结果仍是独立账户路径，不强造相同入场或配对交易的因果PnL。

正常和双倍成本分别评价扣费净收益、完整平仓净收益、开放风险与预计退出成本、最大采样回撤、频繁进出和费用占比、假跌破／回抽止损、错失赢家，以及利润是否依赖一笔最佳交易。提前确认如果只增加被止损交易，必须如实报告；若没有新增机会，也不能宣称两者收益等价或候选有效。

对“假突破”的诊断以真实新增入场之后的原保护退出、后续已收观察及输入覆盖为依据；不为统计预先虚构未观察的日内极值、未成交反向单或收益。数据不可用和未平仓窗口标记为未完成或不可比较，不能按零损益补齐。
